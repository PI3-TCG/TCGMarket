# Diagrama de Caso de Uso

### Ator Usuário:

- Cadastrar-se / Autenticar-se (RF01)
- Buscar/filtrar cartas (RF03, RF13)
- Anunciar carta para venda (RF11)
- Efetuar compra (RF20/RF02)
- Propor troca (RF12)
- Gerenciar carrinho (RF05)
- Gerenciar lista de desejos (RF06)
- Gerenciar perfil (RF07)
- Gerenciar minha coleção (RF16)
- Avaliar usuário (comprador/vendedor) (RF14)
- Consultar histórico de transações (RF15)
- Comparar preços entre vendedores (RF19)

### Ator Administrador:

- Moderar anúncios (aprovar/remover denúncias) (RF18)
- Gerenciar usuários (banir, suspender) (RF18)
- Gerenciar acesso 
- Manutenção
