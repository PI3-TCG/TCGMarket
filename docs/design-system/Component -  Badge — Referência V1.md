# Badge — Referência V1

## 1. Propósito

O Badge é utilizado para apresentar informações curtas e categóricas sobre um elemento.

No TCG Market, será utilizado principalmente para indicar tipo de transação, condição, raridade, status e outras características rápidas.

## 2. Variantes

| Variante      | Uso                                | Fundo                   | Texto     | Exemplos                  |
| ------------- | ---------------------------------- | ----------------------- | --------- | ------------------------- |
| **Primary**   | Identificação relacionada à marca  | `#F0E3F0`               | `#660366` | Favorito · Destaque       |
| **Secondary** | Informação relacionada à interação | `#E4F1FF`               | `#0969D7` | Troca · Novo              |
| **Success**   | Estado positivo                    | Fundo suave de verde    | `#15803D` | Disponível · Vendido      |
| **Warning**   | Atenção                            | Fundo suave de laranja  | `#D97706` | Poucas unidades · Atenção |
| **Error**     | Estado negativo                    | Fundo suave de vermelho | `#B91C1C` | Indisponível · Problema   |
| **Neutral**   | Informação neutra                  | `#F4F4FD`               | `#484B5A` | Usada · Comum             |

## 3. Propriedades

| Propriedade            | Valor                   |
| ---------------------- | ----------------------- |

## 5. Regras de uso

* O Badge deve apresentar informação curta.
* Não utilizar Badge como substituto de Button.
* Não utilizar cores semânticas sem significado semântico.
* Evitar excesso de Badges no mesmo componente.
* O texto deve ser curto e facilmente escaneável.
