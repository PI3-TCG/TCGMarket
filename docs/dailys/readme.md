# Dailys — TCGMarket

Esta pasta registra as dailys realizadas pelo time durante o desenvolvimento do TCGMarket.

O objetivo é acompanhar a evolução do projeto, registrar impedimentos e deixar visível o que cada integrante está desenvolvendo durante as sprints.

## Estrutura

Cada daily deve responder de forma objetiva:

1. O que fiz desde a última daily?
2. O que vou fazer agora?
3. Existe algum impedimento?

## Nome dos arquivos

Utilizar o padrão:

```text
daily-DD-MM-AAAA.md
```

Exemplo:

```text
daily-30-09-2026.md
```

## Regras

- Manter as respostas curtas e objetivas.
- Informar as issues relacionadas sempre que possível.
- Não utilizar a daily para documentação técnica extensa.
- Impedimentos devem indicar claramente o que está bloqueando a atividade.
- Cada integrante é responsável por atualizar sua própria seção.
