### **O que é Spike**

É uma atividade de investigação utilizada em metodologias ágeis, como o Scrum, para reduzir incertezas e esclarecer dúvidas antes ou durante o desenvolvimento de uma funcionalidade.

Ele é usado quando a equipe não possui informações suficientes para estimar ou implementar uma tarefa com segurança. Nesse caso, os desenvolvedores realizam pesquisas, testes, experimentos ou protótipos para entender melhor o problema antes de avançar com o projeto

### **Quais são os tipos de tarefas**

-  **Technical Spike** Investiga dúvidas relacionadas à tecnologia, código ou infraestrutura.
- **Functional Spike** Investiga como uma funcionalidade deve funcionar e quais são seus requisitos.
- **Research Spike** Busca informações sobre uma tecnologia, ferramenta ou solução antes de escolher como utilizá-la.
- **Prototype Spike** Cria um protótipo ou teste simples para validar se uma ideia funciona na prática. 

### **O que é Planning Poker?**

O Planning poker é uma técnica utilizada em metodologias ágeis, como o Scrum, para estimar o esforço e a complexidade de tarefas de desenvolvimento de software.

Nessa técnica, cada integrante da equipe escolhe uma carta com um valor de estimativa, geralmente usando números como 1, 2, 3, 5, 8 e 13. As cartas são reveladas ao mesmo tempo e, caso existam diferenças entre as estimativas, a equipe discute os motivos e realiza uma nova votação.

### **Metodologia Ágil**

Basicamente a metodologia agil é uma forma de desenvolver projetos, principalmente softwares, que valoriza a flexibilidade, a colaboração entre a equipe e a entrega contínua de resultados.
Diferente de modelos tradicionais, em que todo o projeto é planejado antes de começar, o Ágil permite que o trabalho seja dividido em pequenas etapas, facilitando mudanças e melhorias durante o desenvolvimento.
